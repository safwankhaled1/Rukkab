# ركاب | Rukkab

تطبيق لتنظيم المواصلات في فلسطين، مع واجهات للركاب والسائقين ولوحة إدارة مستقلة للمالك.

## محتويات المشروع

- `apps/mobile`: تطبيق Flutter لأندرويد وآيفون، مع دعم العربية والإنجليزية.
- `apps/admin`: موقع إدارة React + TypeScript، بمصادقة ثنائية وصلاحيات المالك والموظف.
- `supabase`: قاعدة البيانات، قواعد البيرميت والحجوزات والمقاعد، صلاحيات البيانات والوثائق، ومهام الإشعارات.
- `tests`: اختبارات قواعد قاعدة البيانات والأمان، واختبار متصفح للوحة الإدارة.
- `docs`: توثيق التشغيل والبنية والعقود البرمجية وتسليم المشروع لفريق مستقبلي.

## معاينة لوحة الإدارة

```powershell
npm ci
npm run dev
```

افتح `http://127.0.0.1:5173` ثم اضغط «استعرض النسخة التجريبية». البيانات التجريبية وهمية والتعديلات في الذاكرة فقط، وتعود لحالتها الأصلية عند إعادة تحميل الصفحة. النظام الحقيقي يحتاج إعداد الخدمات كما في [دليل التشغيل](docs/setup.md).

## الفحوصات

```powershell
npm run check
# بعد تشغيل موقع الإدارة، ومع وجود Edge:
node tests/admin.browser.mjs
# بعد تنزيل Flutter وحزم الموبايل:
./scripts/check-mobile.ps1
```

اختبارات SQL تنفذ العمليات الفعلية على PostgreSQL مضمّن باستخدام PGlite، وتشمل صلاحيات RLS وسياسات حاوية الوثائق بجداول تحاكي بيئة Storage. هذه البيئة تسلسل الاستعلامات على اتصال واحد، لذلك اختبار الطلبات المتزامنة هنا لا يعوض اختبار اتصالين مستقلين في PostgreSQL الحقيقي قبل الإطلاق. وظائف PostGIS وpg_cron وتكامل Supabase Storage/Realtime تحتاج أيضًا فحصًا على مشروع staging.

## قواعد لا تتغير داخل الواجهات

- لا تشغيل لسائق قبل اعتماد الوثائق والسيارة والخط من الإدارة.
- لا رحلة نقل مشترك خارج المسار المعتمد.
- لا تعديل مباشر للمقاعد أو الصلاحيات من التطبيق؛ الخادم يتحقق داخل معاملة واحدة.
- التكسي الخاص يحجز السيارة كاملة، والسعر ثابت قبل إرسال الطلب.
- الإلغاء مجاني، مع سياسة تعليق ٧ أيام عند ٣ مخالفات خلال ٣٠ يومًا وإمكانية الاعتراض.
- لا يتاح موقع السائق بعد الإلغاء أو النزول.

راجع [الحالة الحالية والفحوصات المثبتة](docs/current-status.md) و[دليل الهوية والتصميم](docs/design-system.md).

## حالة التسليم

هذه نسخة تطوير محلية v0.1، وليست خدمة منشورة أو تطبيقًا موقّعًا في المتاجر. الحسابات الحقيقية والخرائط والإشعارات الخارجية تحتاج مفاتيح الخدمات وإعدادها. راجع [البنية](docs/architecture.md) وحدود النسخة الحالية، و[واجهات الخادم](docs/api.md) قبل التطوير التالي.
